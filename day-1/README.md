# Den 1 — Proč M365 API: mapa, formáty a první skript

Onboarding do sdíleného GA tenantu a pravidla práce, evangelizační mapa API nad M365
(proč se automatizace nebát: data zůstávají v tenantu, oprávnění jsou vymezená, všechno
je auditovatelné), formáty dat (JSON, YAML, XML, CSV + UTF-8 pro česká data), PowerShell od nuly a první vlastní skript
vygenerovaný s M365 Copilot Chat, přečtený a otestovaný.
