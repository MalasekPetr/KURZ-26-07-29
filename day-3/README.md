# Den 3 — Data, šablony a správa rozšíření

Microsoft Graph hands-on se zásobníkem živých dotazů nad reálnými daty, výroba prostředí
ze šablon (site a list templates), správa toho, co v tenantu běží (SPFx: App Catalog,
API access, tenant-wide extensions), orientace v Azure a mini-capstone: každý účastník
dodá vlastní otestovaný skript. Uzavírá automatizační část kurzu.

| Pořadí | Blok | Slug | Typ |
|---|---|---|---|
| 1 | Microsoft Graph prakticky *(Lab 4 + živá dema)* | [`graph-fundamentals`](graph-fundamentals/) | P |
| 2 | Site templates & list templates *(lab)* | [`site-list-templates`](site-list-templates/) | P |
| 3 | Správa SPFx: App Catalog, API access, extensions *(demo)* | [`spfx-admin`](spfx-admin/) | P |
| 4 | Azure orientace: subscription, RBAC, kontejnery *(demo)* | [`azure-orientation`](azure-orientation/) | P |
| 5 | Node.js & TypeScript — druhá cesta k API *(demo)* | [`opt-node-typescript`](opt-node-typescript/) | V |
| 6 | Orchestry — úvod do 3rd-party governance | [`opt-orchestry-intro`](opt-orchestry-intro/) | V |
| 7 | Mini-capstone: vlastní skript s Copilot Chat *(Lab 5)* | [`capstone-mini`](capstone-mini/) | P |

> [!NOTE]
> Nejnabitější den kurzu — povinné bloky zaberou ~5 h 45 min, volitelné se spouští jen
> při reálné rezervě. Osa: **čtu data** → **vyrábím prostředí ze šablon** → **spravuji,
> co v tenantu běží** → **vím, kde to poběží** → **skládám vlastní skript**. Blok 3
> (SPFx API access) přímo navazuje na permissions a least privilege z D2 — je to tenant-wide
> rozhodnutí se stejnou logikou jako app registrace. Capstone se nekrátí: je hlavním
> výstupem automatizační části a zdrojem osobních „first automation" plánů.
